# 🎬 Netflix - Rastreador de Filmes Assistidos

Uma aplicação web interativa para marcar e acompanhar todos os filmes que você já assistiu, com categorização automática e armazenamento local.

## ✨ Características

- ✅ **Adicionar filmes** com nome, categoria e data de lançamento
- 📊 **Estatísticas em tempo real** (total de filmes e categorias)
- 🎯 **11 categorias** predefinidas (Ação, Comédia, Drama, etc.)
- 💾 **Armazenamento local** (localStorage) - seus dados persistem
- 🗑️ **Gerenciamento fácil** - remover filmes individuais ou tudo de uma vez
- 📱 **Design responsivo** - funciona em desktop, tablet e mobile
- 🎨 **Interface moderna** com gradientes e animações suaves
